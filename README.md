# Argon 360° defect review

[Open the interactive report](https://haaaarvey.github.io/argon-360-defect-review/).

Static publication of the reviewed Argon decision-order A/B scenario report from 27 October 2026. Contains the original report page and its 286 required images, with image pixels and report text preserved.

The report covers sampled views, development regression examples, and a separate detail-crop trial. These are qualitative AI-assisted observations, not expert ground truth, formal accuracy measurements, or a full-video survey. See the report for all limitations.

This repository does not include the source video, private lineage metadata, local project files, or model-session logs.
